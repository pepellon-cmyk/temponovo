# Sistema de Análise de Desempenho - Kite Surf 🏄‍♂️

Sistema web para análise de desempenho de atletas de kite surf com visualização gráfica de critérios.

## Características

- **Gráfico Radar/Spider** customizado mostrando 9 critérios de desempenho
- **Detalhes dos Critérios** com barras de progresso coloridas
- **Resumo Geral** com média, pontos fortes e pontos a melhorar
- **Seleção de Atletas** para comparar diferentes perfis
- **Design Responsivo** com gradientes modernos

## Critérios Avaliados

1. **Força** - Potência física do atleta
2. **Agilidade** - Capacidade de movimentação rápida
3. **Velocidade** - Desempenho em alta velocidade
4. **Controle** - Domínio do kite e prancha
5. **Comando** - Habilidade de comando do equipamento
6. **Prancha Esquerda** - Técnica com prancha no lado esquerdo
7. **Prancha Direita** - Técnica com prancha no lado direito
8. **Bodydrag** - Técnica de arrasto corporal
9. **Contra Vento** - Desempenho navegando contra o vento

## Como Usar

1. Abra o arquivo `index.html` em um navegador web moderno
2. Selecione um atleta no dropdown
3. Visualize o gráfico radar com todos os critérios
4. Analise os detalhes individuais de cada critério
5. Veja o resumo geral com pontos fortes e fracos

## Tecnologias

- HTML5
- CSS3 (com gradientes e animações)
- JavaScript (Canvas API para gráficos)
- Sem dependências externas
